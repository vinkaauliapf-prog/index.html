The Magic Formula! ✨

Grammar Focus
➕ POSITIVE (+)
I / You / We / They + LIKE
Example: "I like pizza."
He / She / It + LIKES (+ -S)
Example: "She likes tennis."
⭐ Subject tunggal (He, She, Natalie) wajib tambah -S!
➖ NEGATIVE (-)
I / You / We / They + DON'T LIKE
Example: "They don't like spicy food."
He / She / It + DOESN'T LIKE
Example: "He doesn't like winter."
⚠️ INGAT! Setelah DOESN'T, kata kerja kembali ke LIKE (TANPA -S)!

❌ No, she doesn't.
Notice: After Does, use like (no -s)!

✅ LIKE (Subject: They)
4. Natalie ( don't / doesn't ) like thick pizza.
✅ DOESN'T (Natalie = She)
